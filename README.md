# Магазин спичек «Чирк»

Практика по EF Core: консольное приложение на C# с базой PostgreSQL.

Условие задания — по ссылке от преподавателя.

## Как запустить

1. Code → Codespaces → Create codespace on main.
2. Дождитесь, пока поднимутся .NET и PostgreSQL (несколько минут при первом запуске).
3. В терминале: `dotnet run`.

Подключение к базе: `Host=localhost;Database=match_shop;Username=postgres;Password=postgres`.
