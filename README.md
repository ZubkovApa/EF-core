# Trap Time (Ловушка времени)

Приложение для бронирования и управления квестами в реальном времени.

## Автор
Гусаренко Влад, группа РПО 24/2 

## О проекте
Тема: Квест-комнаты. 
Название заведения: Квест-рум «Ловушка времени».
Это место, где команды друзей могут проверить свою смекалку и нервы, проходя сюжетные квесты. Приложение нужно администраторам для бронирования времени и учета прохождений, а также для того, чтобы видеть, какие квесты популярны. Наше заведение отличается тем, что у нас есть квесты с нелинейным сюжетом и «живыми» актерами, а также мы выдаем скидки командам, которые проходят квесты быстрее установленного времени.
